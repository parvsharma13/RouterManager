# Product

## Register

product

## Platform

android

## Users

Hyperoptic Internet customers who use a supported Hyperhub and want a clear, local way to understand and manage their home network from an Android phone. The primary workflow is checking network health, identifying devices, sharing Wi-Fi details, and reaching safe everyday controls without learning router terminology.

## Product Purpose

Router Manager turns a technical Hyperhub administration interface into a dependable household network app. Success means a user can understand the state of their internet in seconds, find and identify a device quickly, and know whether an action is truly supported before using it.

## Positioning

The standalone, open-source Hyperoptic router companion that keeps network data at home and never pretends an unverified control works.

## Brand Personality

Crisp, technical, and precise. The voice is calm and direct, with plain explanations where router behaviour is uncertain.

## Anti-references

Do not resemble a cluttered stock router dashboard, a generic card-grid admin template, or a visual copy of eero. Do not use Hyperoptic, Zyxel, Amazon, or eero branding in a way that implies endorsement.

## Design Principles

- Status before settings: answer whether the network is healthy before exposing configuration.
- Familiar mobile structure: use standard Android navigation and controls without ornamental reinvention.
- Progressive technical depth: show household language first and protocol detail only in contributor diagnostics.
- Honest capability boundaries: distinguish verified, experimental, read-only, and unavailable behaviour.
- Local by default: no account, cloud relay, analytics, or telemetry.

## Accessibility & Inclusion

Target WCAG 2.2 AA. Support 200% text scaling, TalkBack labels, visible focus, 48dp touch targets, dark mode, colour-independent status cues, and reduced motion.
